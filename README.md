# Garry's Mod CoD Maps

Call of Duty multiplayer maps ported to Garry's Mod, ready to play with bots.

| Map | From | Download |
|---|---|---|
| **Castle** (`mp_waw_castle`) | Call of Duty: World at War | [Castle-GMod.zip](https://github.com/siniscy/Gmod-CoD-Maps/releases/latest/download/Castle-GMod.zip) (101 MB) |
| **Carrier** (`mp_bo2carrier`) | Call of Duty: Black Ops II | [Carrier-GMod.zip](https://github.com/siniscy/Gmod-CoD-Maps/releases/latest/download/Carrier-GMod.zip) (66 MB) |

## Install

1. Download the zip for the map you want.
2. Extract it into `garrysmod/addons/`. You should end up with `garrysmod/addons/mp_waw_castle/` or `garrysmod/addons/mp_bo2carrier/`.
3. Start Garry's Mod and pick the map from the map list.

Each zip is self-contained. You don't need Counter-Strike: Source or any other addon, and each map includes a saved navmesh, so bots can use it straight away.

If you already have an older copy of a map, delete that folder first.

These maps work on their own and with the [Gmod Trickshotting Mod](https://github.com/siniscy/Gmod-Trickshotting-Mod).
